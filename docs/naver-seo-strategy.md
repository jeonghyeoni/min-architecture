# 민건축 네이버 검색 상위노출 전략

작성일: 2026-07-26
대상 사이트: https://min-architecture.vercel.app
업종: 종합 건축·인테리어 (경기도 용인시 처인구 양지면)

---

## 0. 먼저 알아야 할 전제 — 네이버는 구글과 게임이 다르다

이 문서 전체를 관통하는 가장 중요한 사실부터 짚습니다.

**"용인 인테리어" 같은 지역+업종 키워드를 네이버에 검색하면, 화면 상단은
파워링크(광고) → 플레이스(지도) → 인플루언서/블로그 → VIEW 순으로 채워집니다.
자체 웹사이트가 노출되는 "웹사이트" 탭은 한참 아래에 있거나, 모바일에서는
스크롤을 여러 번 내려야 나옵니다.**

즉 사이트 코드를 아무리 완벽하게 최적화해도, 그것만으로 "용인 인테리어"
1페이지 상단에 뜨는 일은 일어나지 않습니다. 이건 기술력의 문제가 아니라
네이버 검색 결과 화면의 구조 문제입니다.

그래서 목표를 이렇게 나눠 잡아야 합니다.

| 목표 | 어디서 이기나 | 현실적 난이도 |
|---|---|---|
| "민건축" 검색 시 사이트가 최상단 | 웹사이트 탭 + 플레이스 | 쉬움 (1~2개월) |
| "양지면 인테리어" 등 세부 지역어 | 플레이스 + 블로그 | 중간 (2~4개월) |
| "용인 인테리어" 등 대표 키워드 | **플레이스 + 블로그가 8할** | 어려움 (6개월+) |

**사이트 최적화는 "필요조건"입니다. 충분조건은 네이버 플레이스와 블로그입니다.**
이 문서는 사이트(1~2단계)를 먼저 끝내고, 플레이스·블로그(3~5단계)로
넘어가는 순서로 짜여 있습니다.

## 1. 시장 조사 계획

### 1-1. 키워드 후보군 정의

세 축으로 나눠 수집합니다.

**축 A — 지역 × 공종 (핵심 매출 키워드)**

```
용인 인테리어        용인 리모델링       용인 주택건축
처인구 인테리어      처인구 리모델링     용인 단독주택 신축
용인 집수리          용인 방수공사       용인 증축
용인 대수선          용인 누수공사       용인 전원주택
```

**축 B — 읍면동 세부 지역 (경쟁 낮은 진입점)**

```
양지면 인테리어      포곡읍 인테리어     모현읍 리모델링
남사읍 집수리        백암면 주택건축     원삼면 방수
```

**축 C — 정보성 롱테일 (블로그 유입용)**

```
용인 인테리어 비용        30평 주택 리모델링 비용
단독주택 증축 절차        대수선 신고 방법
옥상 방수 견적            시골집 리모델링 주의사항
전원주택 짓는 순서        인테리어 업체 고르는 법
```

### 1-2. 조사 방법 (직접 하셔야 하는 부분)

| 도구 | 주소 | 무엇을 얻나 |
|---|---|---|
| 네이버 키워드도구 | searchad.naver.com → 도구 → 키워드도구 | 월간 검색량(PC/모바일), 경쟁정도, 연관 키워드 |
| 네이버 데이터랩 | datalab.naver.com | 검색 추이 계절성 (건축은 3~5월, 9~10월 성수기) |
| 네이버 검색 직접 | search.naver.com | **실제 1페이지에 뭐가 뜨는지** — 가장 중요 |

**⚠️ 키워드도구는 반드시 네이버 검색광고 계정(무료 가입)이 필요합니다.
광고를 집행하지 않아도 키워드도구는 쓸 수 있습니다.**

### 1-3. 기록 양식

아래 표를 채우시면 제가 우선순위를 계산해 드립니다.

| 키워드 | 월 검색량(PC) | 월 검색량(모바일) | 경쟁정도 | 1페이지 상단 구성 | 우선순위 |
|---|---|---|---|---|---|
| 용인 인테리어 | | | | 파워링크 n개 / 플레이스 n개 / 블로그 n개 | |
| 처인구 인테리어 | | | | | |
| 양지면 인테리어 | | | | | |
| 용인 집수리 | | | | | |

> **우선순위 공식**: `검색량 ÷ 경쟁강도`가 높고, 1페이지에 **플레이스나 블로그가
> 많이 뜨는** 키워드부터 공략합니다. 파워링크만 잔뜩 뜨는 키워드는 광고비 싸움이라
> 초기에는 피하는 게 맞습니다.

## 3. 실행 순서

### ✅ 1단계 — 사이트 내부 최적화 (완료, 이번 커밋)

무엇을 고쳤는지는 [4장](#4-이번-커밋에서-실제로-바꾼-것)에 정리했습니다.

### ⬜ 2단계 — 네이버 서치어드바이저 설정 (사장님이 30분이면 끝)

`searchadvisor.naver.com` 접속 후:

1. 사이트 소유확인 — **이미 완료된 상태입니다** (HTML 태그가 코드에 들어있음)
2. **요청 → 사이트맵 제출** → `https://min-architecture.vercel.app/sitemap-index.xml`
3. **요청 → 웹페이지 수집** → 홈, /projects, /contact 각각 수집 요청
4. **검증 → 웹마스터 도구**로 robots.txt 인식 확인
5. 2주 뒤 **리포트 → 사이트 최적화**에서 점수 확인

> 사이트맵을 제출하지 않으면 네이버는 사이트를 거의 수집하지 않습니다.
> 이 단계를 빼먹으면 1단계 작업이 통째로 무의미해집니다. **반드시 하세요.**

### ⬜ 3단계 — 네이버 플레이스 최적화 (가장 투자 대비 효과 큼)

지역 검색 순위의 절반 이상이 여기서 결정됩니다.

**등록·정비 체크리스트**

- [ ] 스마트플레이스 등록 (`smartplace.naver.com`) — 사업자등록증 필요
- [ ] 업체명: `민건축` (키워드 욱여넣기는 오히려 제재 대상, 상호 그대로)
- [ ] 업종: `건축업` + `인테리어` 복수 설정
- [ ] **주소·전화번호를 사이트와 글자까지 동일하게**
      → `경기도 용인시 처인구 양지면 용곡로 38-4 1호` / `0507-1359-6512`
      (이번 커밋에서 사이트 쪽을 이 표기로 통일해 뒀습니다)
- [ ] 대표 사진 + 시공사례 사진 **최소 30장** 업로드
- [ ] 상세설명에 공종·시공지역 자연스럽게 서술
- [ ] **홈페이지 항목에 사이트 주소 등록** ← 플레이스→사이트 유입 경로
- [ ] 네이버 톡톡 연결
- [ ] '소식' 기능으로 월 2회 이상 시공 현황 게시

**리뷰 확보 (순위에 직결)**

- [ ] 공사 완료 시 영수증 리뷰 요청을 **표준 절차로 고정**
- [ ] 목표: 3개월 내 방문자 리뷰 30개+
- [ ] ⚠️ 리뷰 대가 지급·매크로는 네이버 제재 사유입니다. 실제 고객 리뷰만.

### ⬜ 4단계 — 네이버 블로그 (대표 키워드 공략의 핵심)

"용인 인테리어" 같은 키워드에서 실제로 1페이지를 먹는 건 블로그입니다.

**초기 세팅**

- [ ] 블로그 개설, 이름 `민건축 - 용인 처인구 주택건축·인테리어`
- [ ] 프로필에 지역·연락처·홈페이지 링크
- [ ] 카테고리: `시공사례 / 공사 비용정보 / 자재 이야기 / 현장 일지`

**발행 계획 — 주 2~3회, 최소 3개월 (이게 최소 조건입니다)**

| 주차 | 유형 | 제목 예시 |
|---|---|---|
| 1 | 시공사례 | 용인 처인구 양지면 30평 단독주택 인테리어 시공 후기 |
| 1 | 정보성 | 용인 인테리어 비용, 평당 얼마나 들까요 (2026년 기준) |
| 2 | 시공사례 | 용인 포곡읍 주택 옥상 방수공사 - 누수 원인부터 잡았습니다 |
| 2 | 정보성 | 단독주택 증축 절차와 인허가, 순서대로 정리했습니다 |
| 3 | 시공사례 | 처인구 모현읍 시골집 대수선 전후 비교 |
| 3 | 정보성 | 인테리어 업체 고를 때 꼭 확인할 5가지 |

**포스팅 작성 규칙 (네이버 C-Rank / D.I.A. 로직 대응)**

- 글자 수 1,500자 이상
- **직접 찍은 사진 15장 이상** (스톡 이미지는 감점, 현장 사진이 강력)
- 제목·본문 첫 문단·마지막 문단에 목표 키워드 배치
- 같은 키워드 반복은 본문당 5~7회까지 (그 이상은 어뷰징 판정)
- 동영상 1개 삽입 시 체류시간 상승 → 순위에 유리
- **모든 글 하단에 사이트 시공사례 링크** ← 블로그 신뢰도를 사이트로 흘려보냄
- ⚠️ 타 블로그 글 복사·AI 대량 생성은 저품질 처리됩니다. 현장 사진과
  실제 경험이 담긴 글이 결국 이깁니다.

### ⬜ 5단계 — 지식iN·카페 (보조)

- [ ] 지식iN에서 `용인 인테리어`, `집수리 업체` 질문에 성실 답변 (주 2~3건)
- [ ] 용인 지역 맘카페·주민카페 가입 후 활동 (**직접 홍보는 강퇴 사유**,
      정보 제공 위주로 신뢰 쌓은 뒤 자연스럽게)

### ⬜ 6단계 — 자체 도메인 (권장)

`vercel.app` 서브도메인은 네이버 웹수집에서 신뢰도가 낮게 평가되고,
공유 도메인이라 사이트 등록 자체가 반려되는 경우도 있습니다.

- [ ] `minarchitecture.co.kr` 등 도메인 구매 (연 1~2만원)
- [ ] Vercel에 연결
- [ ] `astro.config.mjs`의 `site`, `public/robots.txt`, `src/lib/seo.ts`의
      `SITE_URL` 세 곳을 새 주소로 교체 (**이 세 곳만 고치면 전체 반영됩니다**)
- [ ] 서치어드바이저에 새 도메인 재등록

## 4. 이번 커밋에서 실제로 바꾼 것

### 🔴 치명적 버그 수정 — 모든 페이지의 제목이 동일했음

`BaseLayout.astro`가 `<title>`을 **하드코딩**하고 있었습니다.
각 페이지가 `title="프로젝트 | 민건축"` 같은 값을 넘기고 있었는데 레이아웃이
그 값을 아예 받지 않아 **전부 무시**되던 상태였습니다.

그 결과 홈, 시공사례, 문의, 모든 시공사례 상세 페이지가
같은 제목·같은 설명을 달고 있었고, 검색엔진 입장에서는 이게
**중복 콘텐츠**로 보입니다. 색인에서 대부분의 페이지가 제외되는 원인입니다.

→ 레이아웃을 props 기반으로 재작성해 페이지마다 고유한 제목·설명이 나가도록 수정.

### 그 외 적용 항목

| 항목 | 이전 | 이후 |
|---|---|---|
| 페이지별 title/description | ❌ 전 페이지 동일 | ✅ 전부 고유 |
| canonical | ❌ 없음 | ✅ 전 페이지 |
| og:image / og:url / og:type | ❌ 없음 | ✅ + OG 이미지 신규 제작 |
| 구조화 데이터 | ❌ 없음 | ✅ GeneralContractor, WebSite, Breadcrumb, FAQPage, Article, CollectionPage |
| Yeti/NaverBot 메타 | ❌ 없음 | ✅ |
| geo 메타 (지역 신호) | ❌ 없음 | ✅ |
| robots.txt | 기본형 | ✅ Yeti 명시 + 필터 파라미터 차단 |
| sitemap | 기본형 | ✅ priority/changefreq/lastmod |
| 홈 h1 | "작은 일 하나에도 최선을 다합니다" (**키워드 0개**) | ✅ 지역+공종 키워드 포함 |
| 이미지 alt | "전", "후", 제목만 | ✅ "지역 + 공종 + 시공사례" 서술 |
| FAQ | 4개, 구조화 없음 | ✅ 6개, 검색어 기반 + FAQPage 스키마 |
| NAP 일관성 | 페이지마다 표기 상이 | ✅ `src/lib/seo.ts` 단일 관리 |

### 코드 구조

사업자 정보·키워드·스키마 생성기를 **`src/lib/seo.ts` 한 곳**에 모았습니다.
주소나 전화번호가 바뀌면 이 파일만 고치면 사이트 전체(푸터, 문의 페이지,
구조화 데이터)에 동시 반영됩니다. 플레이스 정보와 어긋나는 사고를 막기 위한 구조입니다.

FAQ는 `src/data/faq.ts`에 두어 **화면 표시와 FAQPage 스키마가 같은 원본**을
쓰도록 했습니다. 둘이 어긋나면 검색엔진이 구조화 데이터를 통째로 무시합니다.

## 5. 사장님께 요청드릴 데이터

아래 항목을 알려주시면 그에 맞춰 코드와 전략을 정밀 조정하겠습니다.
**답변 전에도 위 1단계 작업은 지금 그대로 유효합니다.**

### 🔴 지금 당장 필요 (이게 있어야 다음 단계 진행)

1. **최우선 목표 키워드 1~3개**
   - 현재는 `용인 처인구 인테리어 / 주택건축 / 리모델링` 기준으로 작성해 두었습니다
   - 다른 키워드가 목표라면 알려주세요
2. **네이버 플레이스 등록 여부 + 등록되어 있다면 플레이스 URL**
   - 홈페이지 About 사진이 네이버 플레이스 CDN 주소인 걸 보면 등록되어 있을
     가능성이 높아 보입니다
3. **자체 도메인 보유 여부 / 구매 의향**

### 🟡 확인 필요 (현재 코드에 들어간 값이 맞는지)

4. **이메일 주소** — `hello@minarchitecture.com`이 실제 사용하는 주소인가요?
   (더미 주소라면 잘못된 연락처가 구조화 데이터에 박힙니다)
5. **영업시간** — 현재 "24시간 연중무휴"로 되어 있습니다. 실제와 다르면
   `src/lib/seo.ts`의 `openingHours`를 고치겠습니다
6. **사무실 좌표** — 현재 양지면 중심 좌표(37.2342, 127.2758)를 넣어두었습니다.
   정확한 위치를 알려주시면 교체하겠습니다
7. **사업자등록번호** — 푸터 표기 시 네이버가 보는 사이트 신뢰도에 유리합니다

### 🟢 있으면 더 좋음

8. 네이버 블로그 URL (있다면 사이트와 상호 링크 구조를 짜겠습니다)
9. 시공 가능한 최대 반경 (기흥·수지구까지 가능한지)
10. 대표 시공 사례 3건 (블로그 콘텐츠 우선순위를 정하는 데 씁니다)

## 6. 예상 타임라인

| 시점 | 기대 효과 |
|---|---|
| 즉시 | 카톡·블로그 공유 시 미리보기 카드 정상 노출 |
| 2~4주 | 네이버 웹수집 시작, "민건축" 검색 시 사이트 노출 |
| 1~2개월 | 시공사례 상세 페이지들이 롱테일 키워드로 색인 |
| 2~3개월 | 플레이스 리뷰 축적 시 "양지면 인테리어" 등 세부 지역어 상위 진입 |
| 4~6개월 | 블로그 지수 상승 시 "용인 인테리어" 블로그 탭 진입 |
| 6개월+ | 대표 키워드 플레이스 상위권 경쟁 가능 |

> 네이버 로컬 검색에서 6개월 미만에 대표 키워드 1페이지를 약속하는 업체가 있다면
> 대부분 어뷰징(가짜 리뷰, 매크로)입니다. 적발 시 플레이스가 노출 제외되며
> 복구가 매우 어렵습니다. **정공법이 결국 가장 빠릅니다.**
